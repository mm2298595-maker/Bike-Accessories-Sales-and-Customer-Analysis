# Bike Accessories, Clothing, Components Sales & Customer Analytics Dashboard

## Project Overview

An interactive sales analytics dashboard developed using Microsoft Power
BI to explore bicycle-related sales and customer information. The
project covers bicycles, components, accessories, clothing, returns,
customers, and geographical data.

The report brings together data from nine interconnected tables to
provide an overview of sales performance, product profitability,
returns, and customer characteristics.

## Tools & Technologies

-   Microsoft Power BI
-   DAX (Data Analysis Expressions)
-   Data Modelling
-   Data Visualization

## Dashboard Features

### 1. Executive Overview

-   KPI cards for revenue, orders, profit, customer count, and return
    rate.
-   High-level view of overall sales performance.

### 2. Geographical Sales Analysis

-   Explore revenue, order volume, and customer distribution across
    countries and continents.
-   Compare sales performance across geographical areas.

### 3. Product Performance Analysis

-   Examine product revenue, cost, selling price, profit margins, and
    quantities sold.
-   Analyse returns across bicycle-related product categories, including
    components, accessories, and clothing.
-   Use product-level drill-through to explore individual product
    performance.

### 4. Customer Analysis

-   Explore customer purchasing behaviour and demographic
    characteristics.
-   Segment customers by gender, marital status, occupation, and
    education level.
-   Review customer and revenue patterns across segments.

## Data Model

The report integrates nine interconnected tables covering sales,
returns, customers, products, and geographical information.

1.  Download the `.pbix` file from this repository.
2.  Open it using Microsoft Power BI Desktop.
3.  Interact with the report using its slicers, filters, and
    drill-through features.
